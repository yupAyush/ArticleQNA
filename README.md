# Custom Article Query with GenAI, FAISS & LangChain

This project allows you to make intelligent queries on custom datasets such as articles. It leverages GenAI embeddings for semantic understanding and FAISS as the vector database for fast similarity search. LangChain ties everything together, making it simple to build and scale.

## Features

- Upload or ingest your own article data
- Generate embeddings using GenAI
- Store and search embeddings efficiently with FAISS
- Query data in natural language via LangChain
